# Product Overview - Tuqayyem Mobile Rating App

## Core Concept
Mobile app for rating places, events, restaurants, tourist spots, universities, and stadiums. Users can view locations, submit ratings, and discover new places through a modern, adaptive interface.

## MVP Phases

### MVP v1 (Current Focus)
- **Landing page** with modern design
- **Dashboard** listing locations as cards
- Clean, fast, simple interface

### MVP v2 (Next Phase)  
- **Sign-up/Sign-in flow** with authentication
- **Enhanced dashboard** with user-specific features
- **Rating submission** functionality

## Key User Stories

### Primary Flow
1. User opens app → sees modern landing page
2. User navigates to dashboard → views location cards
3. User signs in → can submit ratings for locations
4. Ratings are saved and displayed in real-time

### Target Users
Anyone looking to discover and rate local places - from restaurants and cafes to universities and stadiums. Focus on authentic user experiences and community-driven ratings.

## Core Entities
- **Location**: Places/events/restaurants/tourist spots/universities/stadiums with name, type, description, ratings
- **User**: App users with authentication and rating history  
- **Rating**: User ratings with value, comment, timestamp

## Design Principles
- **Modern & Light**: Clean, contemporary design with light color palette
- **Platform Adaptive**: Material Design for Android, Cupertino for iOS
- **Fast & Simple**: Quick MVP focused on core functionality
- **Human-Reviewed**: All UI elements (colors, buttons, cards) require human approval

## Quality Standards
- Automated tests for every feature
- Trunk-based development workflow
- Human review required for all UI components
- Performance-focused implementation
